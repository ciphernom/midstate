# Midstate v6.6.1 — Base RPC Fix

Maintenance release addressing Base RPC rate limiting
during decentralised exchange order book synchronisation.

- Changed the default Base RPC provider to PublicNode.
- Improved RPC rate-limit detection and retry handling.
- Increased default order book scan batches from 2,000 to 40,000 blocks.
- Reduced historical order book RPC requests by up to 95%.
- Preserved conservative scanning limits for custom RPC providers.

No consensus changes.

Available through the automatic desktop updater.
