# Midstate v6.7.0 — Privacy Update

A major improvement to default wallet and network privacy without changes to consensus.

## Transaction privacy

- New denomination-aware Self-PayJoin transaction planner.
- Improved payment and change output ambiguity.
- Reduced wallet UTXO fragmentation.
- Improved coin selection and fee estimation.
- Independent input selection for private split payments.
- Randomised private payment output ordering.

## Private name payments

- Encrypted fresh-address negotiation using ML-KEM and XChaCha20-Poly1305.
- Multiple fresh WOTS receiving addresses per payment.
- Improved address caching and allocation limits.
- Backward compatibility with legacy wallets.

## Network privacy

- Extended Dandelion stem routing to Reveal transactions.
- Locally originated stem transactions remain outside the public mempool until fluff.
- Content-based transaction deduplication.
- Preserved mempool admission checks and timeout-based propagation.

## Wallet improvements

- Shared transaction planning and fee calculation across CLI, desktop and web wallets.
- Improved multi-address payment support.
- Additional transaction lifecycle and privacy regression tests.

No consensus changes. No hard fork required.
