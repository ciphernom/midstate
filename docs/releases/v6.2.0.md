# v6.2.0 "Anselmo"

A hard fork. Midstate Walk now starts at block **371,500** instead of
420,000: expected around 10 November 2026, near 12:00 UTC, at 60-second
blocks. The v6 opcodes move to the same block, from 400,000, so one
upgrade covers both. Nothing else about either changes.

**Every node must upgrade before block 371,500.** A node on v6.0.0 to v6.1.1
still expects the BLAKE3 chain until 420,000 and no v6 opcodes until
400,000, so it rejects the first Walk block and stays on a chain the rest
of the network has left. A node on v5 does the same.

Midwimble moves in step: v1.3-DIMEBAG switches at its block 37,300, a few
hours earlier, and checks midstate headers from 371,500 on as Walk proofs.
**Pools that merge-mine midwimble must upgrade both nodes** before the first
of the two switches.

## What changes

- **The switch:** `WALK_ACTIVATION_HEIGHT` is 371,500. Blocks below it keep
  the BLAKE3 chain, so syncing from genesis works as before.
- **The rest of the Walk is v6.0.0's:** the same algorithm and golden
  vectors, and the same 8× difficulty reset at the switch
  (`WALK_TARGET_SHIFT = 3`), after which ASERT takes over.
- **The v6 opcodes come with it:** `OP_NIP`, `OP_TUCK`, `OP_NOT`,
  `OP_LESS_THAN` and `OP_MERKLE_ROOT` are valid from block 371,500
  (`V6_ACTIVATION_HEIGHT`, which must equal `WALK_ACTIVATION_HEIGHT`).
  Below it they are invalid, as before.
- **The web wallet's countdown, the node's miner dashboard, the website and
  the docs** give the new height.

## Mining

- **`midstate miner`, pools, the web wallet and the SDK change over by
  themselves:** templates and `mining.notify` say which proof of work a job
  takes. The node or pool serving them must run v6.2.0. Mining needs no
  SDK update; SDK 2.10.1's compiler and VM take the v6 opcodes from
  371,500.
- **Third-party miners, including MidstateAxe firmware,** must switch at
  371,500. Firmware with 420,000 built in must be updated.
- **Pools:** the share-difficulty advice in `pools.md` (add 4 to
  `--share-bits` at the switch) now applies at 371,500.
- **Merged mining pauses** from midwimble's switch until midstate's, as
  before. The pool merges again by itself once both chains take the Walk.

## Trading MDS for MDW

- **Selling MDS waits for block 371,500.** The wallet places, takes and
  answers those orders only from then on, and the desktop Trade tab says so.
  Open sell-MDS orders are not announced until then. Selling MDW works as
  before.
