# v6.0.1 "Anselmo"

v6.0.0's Linux and Raspberry Pi downloads don't start: they were built against
glibc 2.43 and stop with "version `GLIBC_2.43' not found" on Raspberry Pi OS,
Debian 13, Ubuntu 24.04 and anything older. v5.0.2's had the same fault.
**Use v6.0.1 instead.** It needs glibc 2.39 at most, as v5.0.1 did.

Consensus is v6.0.0's: from block **420,000** the proof of work is Midstate
Walk, and every node must run v6.0.0 or later before then (expected around
mid-December 2026). Everything in the
[v6.0.0 notes](https://github.com/ciphernom/midstate/releases/tag/v6.0.0)
applies. Windows and macOS users on v6.0.0 need this only for the pool
changes below.

## Linux and Raspberry Pi binaries start again

- **Built on Ubuntu 24.04:** the Linux builds had run on GitHub's
  `ubuntu-latest`, which moved to Ubuntu 26.04 and glibc 2.43. They now run
  on Ubuntu 24.04, so they need glibc 2.39 at most: Raspberry Pi OS (trixie),
  Debian 13, Ubuntu 24.04 and later.
- **Checked:** the build reads the glibc each Linux binary needs, and stops
  the release if it is newer than 2.39.

## Pools: browser mining

- **`/pool/api/…`:** the browser API is also served under `/pool/api/…`, so a
  reverse proxy that already forwards `/pool` to the pool's API port carries
  browser miners with no extra rule.
- **Miners paid only in midwimble:** a merge-mining pool also takes miners
  who give only a midwimble address, as the midwimble web wallet does. Their
  shares earn midwimble score, and the pool keeps their midstate part.
  Templates carry a `midwimble` section with the merge status, target,
  reward, the pool's midwimble fee and the miner's score (`pools.md`).

Pools need v6.0.1 for both web wallets' one-tap mining.

## Web wallet

- **One-tap mining:** a link to the wallet's `#mine` makes a wallet and
  starts mining on the default pool (`rpc.cypherpunk.gold/pool`), with a
  countdown to the Walk, an earnings estimate, phone-friendly defaults and a
  pause on low battery. An optional midwimble address in the pool settings
  gets each share's midwimble part paid too.
- **The published wallet mines again:** its deploy now includes the files
  the miner loads, and checks that the site has every file it names.
